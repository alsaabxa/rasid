# منصة راصد — النسخة الجديدة

نسخة منفصلة متعددة المدارس، مستوحاة من واجهة وميزات ملف `zahra pro.html`، ومتصلة بمشروع Firebase جديد عند إعداده. لا تحتوي على بيانات مدرسة القالب أو بيانات من المشروع الإنتاجي.

## ما يتضمنه التطبيق

- طلب تسجيل مدرسة بالبريد/كلمة المرور أو Google، مع اختيار نوع المدرسة (بنين أو بنات).
- اعتماد يدوي لطلبات المدارس من `admin.html`.
- لوحة المدرسة، الفصول، الطلاب، الرصد، QR، أسماء المسؤولات، أولياء الأمور، تقارير الغياب اليومية/الأسبوعية/الشهرية، الطباعة، Excel وPDF، واستيراد الجداول.
- حفظ مستقل لكل مدرسة في `schools/{schoolId}/private` بمستندات متعددة (`v2_*`) وبيانات مراجعة في `appMeta`.
- مزامنة دورية عبر الأجهزة مع Firebase.

## الإعداد الآمن قبل الربط

هذه النسخة غير مرتبطة بأي مشروع Firebase حالي. لإكمال الربط يلزم إنشاء مشروع Firebase جديد، اختيار قاعدة Firestore وموقعها، تفعيل Email/Password وGoogle، ثم وضع إعدادات Web الجديدة في `public/firebase-config.js` وتحديث `.firebaserc`. عيّن بريد إدارة المنصة في `firestore.rules` و`public/admin.html` قبل نشر القواعد. القيم الافتراضية في القواعد تمنع أي حساب من صلاحية إدارة المدارس حتى تُستبدل ببريد الإدارة الجديد.

**لا تنشر قواعد Firestore قبل مراجعة البريد وإعداد المشروع. لا تضف بيانات حقيقية قبل اختبار التسجيل والعزل بين المدارس.**

## تشغيل محلي

تحتاج لإعداد Web App في مشروع Firebase جديد أولًا، ثم شغّل Hosting Emulator باستخدام Firebase CLI. استخدم قناة معاينة قبل النشر الحي. لا يوجد نشر تلقائي للإنتاج مفعّل في هذا المستودع.

## ملاحظات على ملف القالب

تم نقل الوظائف وسير العمل فقط. جرى استبعاد اسم مدرسة القالب ورابط Apps Script القديم وأي بيانات/إعدادات مرتبطة به. لا تنسخ ملف المصدر القديم مباشرة إلى النشر.
