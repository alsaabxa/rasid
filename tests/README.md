# اختبارات راصد

## 1) اختبارات تعمل فورًا (بدون تثبيت أي شيء، Node 20+)

```bash
npm test
```

تحمّل الدوال **الحقيقية** من `public/index.html` داخل سياق معزول لكل «جهاز»، وتشغّلها على Firestore مُحاكى في الذاكرة
(`tests/helpers/fake-firestore.js`) يحسب القراءات ويرفض الوصول لمدرسة غير مدرسة الجهاز.

| الملف | ماذا يغطي |
|---|---|
| `realtime-sync.test.js` | الإضافة/التعديل/الحذف عبر `docChanges`، حماية التعديل المحلي، تجاهل صدى كتابة الجهاز نفسه، عدم الرسم أثناء الإدخال، ترتيب السجلات، `appMeta` |
| `isolation.test.js` | مدرستان لا تتبادلان بيانات، لا محاولات وصول لمسار مدرسة أخرى، تبديل المدرسة وتنظيف الاشتراكات، تجاهل لقطة متأخرة من مدرسة سابقة، تسجيل الخروج، عدم تراكم الاشتراكات |
| `read-count.test.js` | قياس القراءات: الاستطلاع القديم (`fixtures/polling-sync.js`) مقابل المستمع الجديد، وعدّاد الرسائل |

لاختبار نسخة أخرى من الصفحة: `RASID_INDEX=/path/to/index.html npm test`.

## 2) اختبار قواعد Firestore (يحتاج Java وFirebase CLI والمُحاكي)

```bash
npm install
npm run test:rules
```

يختبر `firestore.rules` نفسه: عزل المدارس، المدرسة المعلّقة أو المنتهية تجربتها، الناخب المجهول، الرسائل، التسجيل، المالك،
وأن `list` على `schools/{id}/private` (الذي يحتاجه المستمع اللحظي) مسموح لمدرسته فقط.

> ملاحظة: القسم الأول لا يثبت صحة القواعد نفسها؛ القواعد تُثبت بالقسم الثاني فقط.
